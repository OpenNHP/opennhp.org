IETF 127 ハッカソン — 参加募集

サンフランシスコ、2026年11月14–15日。第2ラウンド：見えないように設計されたインフラを見つけてみてください。

NHP
The OpenNHP Team
2026年9月30日 IETF 127 ハッカソン ゼロトラスト
IETF 126 では誰も破れませんでした。私たちは再び戻り、もう一度お願いします。

IETF 126 では、1か月間の公開テストとハッカソンの週末を通じて、有効な暗号認証なしに NHP で保護されたリソースを発見または到達する方法を示した参加者はいませんでした。2つの独立したチームが成果を公開しています：

  • Darkmoon（フランスの自律型 AI ペネトレーションテストプラットフォーム）はデモに対して完全な評価を行い、保護されたホストでの検出はゼロでした。
  • DugganUSA（米国の脅威インテリジェンス企業）はハッカソン期間中に受動的偵察を実施しました — Certificate Transparency、DNS、Shodan。Access Controller の IP アドレスは見つかりましたが、どれにも開いているポートはありませんでした。また、CT と DNS からは依然としてデモのコンポーネント構成が分かること、そして公開されているサポート用ホストが弱点になりうることを的確に指摘してくれました。

クリーンな結果はデータポイントであって、証明ではありません。そこで サンフランシスコでの IETF 127 に、Network-infrastructure Hiding Protocol (NHP) は同じお願いを携えて再び参加します。

チャレンジ
ぜひ、破ってみてください。

有効な NHP ノックを完了する前に、NHP で保護されたリソースを発見・特定・到達してください。「認証してから接続する」モデルに反するものはすべて対象です：

  • 保護されたサービス、隠されたポート、IP アドレス、ドメイン名の発見
  • 認証または認可の回避
  • 認証前の攻撃対象領域の悪用
  • 暗号上の弱点やプロトコル設計上の欠陥の発見
  • リプレイ、なりすまし、リレーの悪用による攻撃
  • DDoS およびスキャンへの耐性
  • 自律型および AI 支援の攻撃手法
  • 受動的な列挙 — Certificate Transparency、DNS など、保護されたホストに触れずに漏れるメタデータ
IETF 126 以降の変更点

デモ環境はよりシンプルになり、見えない部分が増えました：

  • server.opennhp.org は HTTPS の公開面を一切持たなくなりました — 有効な NHP ノックにのみ応答します
  • ac.opennhp.org は eBPF/XDP でアクセス制御を行うようになりました。未認可の送信元からのパケットはネットワークドライバの段階で破棄され、Linux の TCP/IP スタックやアプリケーションには届きません — そのため、NHP ノックを通過していない者はこれらの層の脆弱性に到達できません
  • demo.opennhp.org は、通常のログインポータルの背後に OpenNHP を置く方法を示します：ユーザーがサインインすると、ポータルがユーザーに代わってノックします
  • agent.opennhp.org はブラウザでの NHP-Agent JavaScript SDK をデモします
  • relay.opennhp.org はブラウザ向けクライアントのために HTTP リクエストを NHP の UDP メッセージに変換します

デモの全体構成をご覧ください — 各ボックスはソースコードにリンクしています。

2つの結果。どちらにも価値がある。
破れた場合
弱点を理解して修正し、それを公表します。プロトコルはより強くなります。
破れなかった場合
コミュニティは、プロトコルのセキュリティ特性について独立したデータポイントをまた一つ得ます。
参加方法

IETF 127 ハッカソンは 2026年11月14–15日（土・日）、Hilton San Francisco Union Square で開催されます。参加は無料、どなたでも参加でき、リモート参加も歓迎します。

  1. ハッカソンに登録してください：registration.ietf.org/127
  2. OpenNHP プロジェクトを探す：IETF 127 ハッカソン Wiki
  3. 早めに始める — ライブデモはすでに公開中なので、週末の前から調査を始められます
  4. コードを読む：GitHub 上の OpenNHP と Internet-Draft
  5. 発見を報告する：GitHub Issue を作成するか、ハッカソン会場で OpenNHP チームに声をかけてください

ご質問は ztcpp@ietf.org または ハッカソンのメーリングリストでどうぞ。
